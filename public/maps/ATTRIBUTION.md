# Cartographic Data Attribution

- **maroc.geojson**: Region boundaries derived from authoritative open sources.
- **maroc-provinces.geojson**: ADM2 Level (Provinces / Prefectures) boundaries sourced from geoBoundaries gbOpen (OpenStreetMap / Wambacher).
- **License**: Open Data Commons Open Database License 1.0 (ODbL).
- **Year**: 2017 / 2023 update.

- **casablanca-boundaries.geojson**: User-supplied OpenStreetMap relation export, licensed under ODbL. The export contains administrative bounding envelopes (`@geometry: bounds`), not full boundary outlines; its extraction date is not recorded. Attribution is shown in the city Market geographic context UI.
